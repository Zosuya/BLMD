# BLMD 使用說明

**BLMD** 讓你在 Blender 裡用 Markdown 寫筆記：左邊用內建的文字編輯器打字，右邊即時顯示排好版的預覽。預覽裡的勾選框可以直接點，連結可以開網頁，也可以直接操作 Blender，例如切換工作區、對準物件、跳到某個節點。

> 這份說明本身就是用 BLMD 顯示的。把它開在預覽裡，邊讀邊點就能試每個功能。

---

## 1. 打開預覽

| 做法 | 快捷鍵 | 結果 |
|:--|:-:|:--|
| 文字編輯器標題列的分割按鈕 | Ctrl+Alt+V | 把區塊左右切開，右邊變成預覽 |
| 文字編輯器標題列的眼睛按鈕 | Ctrl+Shift+V | 同一個區塊在「編輯」和「預覽」之間切換 |
| 預覽標題列的 **Edit** 按鈕 | Ctrl+Shift+V | 切回文字編輯器 |

- 預覽標題列跟文字編輯器一樣有**文字選單**：下拉切換別份筆記、新增、開啟硬碟上的 .md 檔。右邊的 X 只是讓預覽不顯示任何筆記，不會刪掉文字。
- 每個預覽各自記得自己在看哪份筆記。切換工作區、存檔重開之後都還在。
- 同一個畫面已經有這份筆記的預覽時，Ctrl+Alt+V 不會再開第二個。

## 2. 在預覽裡操作

| 操作 | 效果 |
|:--|:--|
| 滾輪 | 上下捲動 |
| Page Up / Page Down | 一次捲一頁 |
| Home / End | 跳到最上面、最下面 |
| 點勾選框 | 打勾或取消，Ctrl+Z 可以復原 |
| 點連結 | 開網頁或操作 Blender（見第 4 節） |
| 滑鼠移到勾選框、連結上 | 游標變成手指 |

點一般文字或空白處不會有任何反應。

## 3. 支援的語法

左邊打字，右邊**即時更新**。換行會照原樣保留，不需要另外空一行。

### 3.1 標題

```
# 大標題
## 中標題
### 小標題
```

大標題和中標題下面會有分隔線。

### 3.2 文字樣式

一般文字、**粗體**、*斜體*、~~刪除線~~、`行內程式碼`。

```
**粗體**  *斜體*  ~~刪除線~~  `行內程式碼`  \*跳脫\*
```

- 斜體畫成正體（Blender 畫字工具沒有斜體字型）。
- 單字中間的底線不會被當成斜體，例如 snake_case_name。
- 前面加反斜線可以顯示符號本身：\*不是斜體\*。

中英混排會自動換行：The quick brown fox jumps over the lazy dog，中文可以在任何字之間斷開，英文單字不會被切斷。

### 3.3 清單

- 第一項
- 第二項
  - 子項目（前面多兩個空格）
    - 再下一層
1. 編號清單
2. 第二步
3. 第三步

### 3.4 勾選框（點了就會改原文）

- [x] 已完成的事
- [ ] 還沒做的事
  - [ ] 子任務也能點

```
- [ ] 待辦
- [x] 完成
```

### 3.5 表格

| 鏡頭 | 動畫 | 打光 | 備註 |
|:--|:-:|:-:|--:|
| S01 | [x] | [x] | 完成 |
| S02 | [x] | [ ] | 等燈光 |
| S03 | [ ] | [ ] | 還沒開始，這格比較長，預覽變窄時會自動換行 |

- 第二行的 `:--`、`:-:`、`--:` 分別代表靠左、置中、靠右。
- 格子以 `[ ]` 或 `[x]` 開頭，會變成可以點的勾選框。這是 BLMD 自己加的寫法，在 GitHub 上會顯示成原文。
- 格子裡要放 `|` 符號時寫成 `\|`。
- 表格太寬時會照內容比例分配欄寬，格子裡的字自動換行。

### 3.6 引用與分隔線

> 引用的文字會變暗，左邊有一條線。
> 可以寫好幾行。

上面是引用，下面是分隔線（`---`）。

### 3.7 程式碼區塊

```python
import bpy

for ob in bpy.context.selected_objects:
    print(ob.name)  # 縮排會保留
```

用三個反引號包起來，用等寬字型顯示，太長會自動換行。

### 3.8 圖片

圖片要**單獨寫成一行**；寫在句子中間的只會顯示說明文字。

```
![說明](checker.png)      硬碟上的圖片
![說明](//textures/wood.png)        // 開頭表示相對於 .blend
![說明](bl:image/圖片名稱)           .blend 裡的圖片
```

![checker](checker.png)

找不到的圖片會顯示提示：

![missing](not_here.png)

- 相對路徑以這份筆記的檔案位置為準。筆記如果是存在 .blend 裡的文字，就以 .blend 所在的資料夾為準。
- 比預覽寬的圖片會等比縮小。
- 不支援網路圖片。

## 4. 連結

### 4.1 網址

- 一般連結：[Blender 官網](https://www.blender.org)
- 直接貼網址也會變成連結：https://docs.blender.org/manual/
- 點了會用預設瀏覽器打開，長連結換行後每一段都能點

```
[顯示文字](https://網址)
```

### 4.2 Blender 連結

網址改成 `bl:` 開頭，點了就直接操作 Blender。名稱要跟 Blender 裡**完全一樣**，有空格也可以。

| 寫法 | 點了會怎樣 |
|:--|:--|
| `bl:workspace/名稱` | 切換工作區 |
| `bl:object/名稱` | 選取物件，3D 視圖對準它（物件約佔畫面一半） |
| `bl:collection/名稱` | 選取集合裡的所有物件並對準 |
| `bl:camera/名稱` | 設成場景攝影機，切到攝影機視角，不改選取 |
| `bl:local/名稱` | 局部視圖（小鍵盤 /）只看這個物件，再點一次退出 |
| `bl:frame/數字` | 時間軸跳到這一格 |
| `bl:node/節點樹/節點` | 節點編輯器跳到這個節點或 Frame |
| `bl:text/筆記名稱` | 預覽換成另一份筆記 |

**試試看**（用 Blender 新檔案預設的內容）：

- 物件：[Cube](bl:object/Cube)、[Camera](bl:object/Camera)
- 集合：[Collection](bl:collection/Collection)
- 攝影機視角：[Camera](bl:camera/Camera)
- 局部視圖：[只看 Cube](bl:local/Cube)（再點一次退出）
- 跳格：[第 1 格](bl:frame/1)、[第 120 格](bl:frame/120)、[第 250 格](bl:frame/250)
- 節點：[世界的 Background](bl:node/World/Background)（視窗裡要有著色器編輯器）
- 工作區：[布局](bl:workspace/布局)、[著色](bl:workspace/着色)（名稱照你的介面語言，英文介面是 Layout、Shading）

### 4.3 節點跳轉的細節

- **節點樹**：依序找材質、節點群組、世界。
- **節點**：先比對內部名稱，再比對你設的標籤。**Frame 也算節點**，直接用 Frame 的標籤最直覺，例如 `bl:node/MyMaterial/Lighting Setup`。
- 只寫節點樹，不寫節點，就顯示整個節點樹。
- 節點編輯器會照 Blender 平常的方式切過去，不會被釘選：
  - 材質：切到選中物件的那一格材質；選中的物件沒有這個材質，就改選用到它的物件。
  - 幾何節點：改選用這個節點群組當修改器的物件。
  - 世界：只限目前場景在用的世界。
- 上面的方式都切不過去時（材質沒有物件在用、節點群組包在別的節點樹裡），才會改用釘選。

### 4.4 連結的範圍與安全

- 物件、集合、攝影機只在**目前場景**裡找；3D 視圖、節點編輯器只在**預覽所在的視窗**裡找。找不到時，左下角會顯示提示。
- `bl:` 連結只能做上表這幾種固定動作，**不能執行任意指令或 Python**。筆記存在 .blend 裡，別人給你的 .blend 也不能拿筆記裡的連結來做壞事。

### 4.5 筆記互相連結

用 `bl:text/` 可以做目錄頁或筆記之間的連結，例如：

```
[回到目錄](bl:text/目錄.md)
```

---

## 5. 限制與注意事項

- **斜體**：畫成正體。
- **硬碟上的圖片**：會被載入成 Blender 的圖片資料。因為沒有東西在用它，存檔時不會存進 .blend。
- **預覽區**：其實是一個「資訊」視窗。切回編輯時會恢復成正常的資訊視窗設定。
